01 · CONCEPTUAL MODEL

01先抓住核心模型

FFM API 统一管理 Java 堆外内存段、函数描述符和函数句柄，减少直接依赖 JNI 的样板代码，同时保留边界检查与生命周期控制。

ARENA

生命周期

Arena 管理一段原生内存的生命周期，关闭后其分配内存不可继续访问。

LAYOUT

布局描述

ValueLayout 描述内存中的字节宽度、对齐与字节序。

HANDLE

本地函数

通过 Linker 与函数描述符获得可调用的外部函数句柄。

  • java.lang.foreign 提供统一的堆外内存、链接器与函数句柄 API。
  • 受限 Arena 默认由创建它的线程管理，并支持确定性的 try-with-resources 释放。
  • FFM API 在 JDK 21 仍是预览能力。
02 · HANDS-ON

02在一个受限 Arena 中读写 int

示例保持最小可读，重点是展示这项能力如何使用，以及它与普通 Java 代码的关系。

MemoryDemo.java 
import java.lang.foreign.Arena;
import java.lang.foreign.MemorySegment;
import java.lang.foreign.ValueLayout;

public class MemoryDemo {
    public static void main(String[] args) {
        try (Arena arena = Arena.ofConfined()) {
            MemorySegment number =
                arena.allocate(ValueLayout.JAVA_INT);

            number.set(ValueLayout.JAVA_INT, 0, 42);
            int value =
                number.get(ValueLayout.JAVA_INT, 0);

            System.out.println(value);
        }
    }
}

先管理生命周期：理解 Arena 的 confined、shared、automatic 等策略，比记住函数调用顺序更重要。

仍必须验证原生边界：内存段带有大小和生命周期约束，但调用不安全的本地库仍需自行验证协议与参数。

03 · BOUNDARIES

03工程中的边界与易错点

能写出示例不代表可以安全迁移。下面两个问题最值得在设计和评审阶段确认。

01WATCH OUT

绕过内存段直接传递裸地址

这会丢失边界与生命周期保护，只在确有必要的底层适配中使用。

02WATCH OUT

Arena 关闭后继续访问

关闭 Arena 会使相关段失效，应在作用域内完成所有访问。
