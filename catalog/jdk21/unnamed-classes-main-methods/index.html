01 · CONCEPTUAL MODEL

01先抓住核心模型

JDK 21 预览一个更轻量的单文件程序模型：源文件可以不显式声明类，并允许实例 main 方法作为程序入口。

FILE

单文件

源文件顶层可以直接声明方法和导入，由编译器创建隐式未命名类。

MAIN

实例入口

启动器可识别非 static 的 main 方法，并创建实例后调用。

SIMPLE

学习友好

目标是降低教学、脚本和原型代码的启动负担。

  • 源文件可以直接包含一个 main 方法，无需显式写 class。
  • 程序启动器支持实例 main 方法作为入口。
  • 未命名类不能被其他类按正式名称引用。
02 · HANDS-ON

02一个无需 class 声明的 Java 单文件

示例保持最小可读，重点是展示这项能力如何使用，以及它与普通 Java 代码的关系。

Hello.java 
void main() {
    String name = "JDK 21";
    System.out.println("Hello, " + name + "!");
}

运行方式：使用 java --enable-preview --source 21 Hello.java 直接运行单文件。

适合小程序：共享 API、模块化和大型工程仍需要具名类与清晰的包结构。

03 · BOUNDARIES

03工程中的边界与易错点

能写出示例不代表可以安全迁移。下面两个问题最值得在设计和评审阶段确认。

01WATCH OUT

把未命名类当成可复用类型

它没有供其他源文件引用的类名，更适合脚本或教学入口。

02WATCH OUT

忽略单文件限制

一个源文件只能有一个未命名类，复杂程序仍应使用显式结构。

04 · SUMMARY

04本章小结

TAKEAWAYS

让小型 Java 程序少一些仪式代码。

  • 小程序的样板代码减少了。
  • 实例 main 方法可以成为入口。
  • 大型工程仍应保持显式类型设计。
